# SmartH2WO Machine Learning Documentation

Welcome to the Machine Learning directory for the SmartH2WO backend. 

We have formalized our Machine Learning documentation into a clean, step-by-step guide. Please read the documentation in the following order:

1. **[01_OVERVIEW.md](./01_OVERVIEW.md)**
   Start here. This document explains the features, limitations, and architectural goals of our ML integration.

2. **[02_TRAINING_GUIDE.md](./02_TRAINING_GUIDE.md)**
   A step-by-step tutorial on how to generate the synthetic dataset and train the machine learning models locally.

3. **[03_INFERENCE_API.md](./03_INFERENCE_API.md)**
   Explains how the FastAPI backend actively uses the trained models to evaluate live sensor data, including our strict rule-based fallback strategy.
